Cloud sync (Firebase)

One-time setup. Your data live-syncs between any device that uses the same Firebase config + Sync Code.

  1. Go to console.firebase.google.com → Add project (any name).
  2. In the project: Build → Firestore Database → Create database (Start in test mode is fine to begin).
  3. Build → Authentication → Get started → Anonymous → Enable.
  4. Project settings (⚙️) → Your apps → add a Web app (</>). Copy the firebaseConfig object and paste it below.
